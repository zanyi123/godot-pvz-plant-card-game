# 🌱 PVZ 植物卡牌对战游戏

一款基于 **Godot 4.6** 引擎开发的《植物大战僵尸》同人回合制策略卡牌游戏。

---

## 🎮 游戏特色

### 核心玩法
- **四大阵营克制**：法 → 射 → 坦 → 法，掌握克制关系事半功倍
- **双卡组合出牌**：主卡 + 辅卡组合，每回合最多出 2 张牌
- **六阶段结算引擎**：即时效果 → 预处理 → 技能触发 → 阵营克制 → 伤害计算 → 回合结束
- **濒死补救机制**：HP 归零时可出牌自救，增加策略深度

### 双难度人机 AI
| 难度 | 策略特点 |
|------|---------|
| **普通** | 简单攻击贪心算法，适合新手熟悉游戏 |
| **大师** | 多维策略决策：阵营克制 / 双卡组合 / 三回合预测 / 留牌防守 / 组合记忆库 |

### 其他功能
- ✅ 50+ 植物卡牌，覆盖法/射/坦/辅四大阵营
- ✅ 局域网联机对战（Host / Client 模式）
- ✅ 成就系统与存档管理
- ✅ 背景音乐与音效
- ✅ PC 与 Android 移动端双端适配

### 💻 Windows 电脑安装教程

#### 系统要求
- **系统**：Windows 10 / Windows 11（64位）
- **磁盘空间**：约 500MB
- **显卡**：支持 OpenGL 3.3（大多数电脑都可以）

#### 安装步骤（3 步搞定）

```
第1步：下载 PVZ-Card-Game_v1.3.0_Windows.zip
         ↓
第2步：右键 → 解压到当前文件夹（或任意位置）
         ↓
第3步：进入解压后的文件夹，双击：
       ✅ PVZ卡牌游戏.exe   或者   启动游戏.bat
```

#### ❓ 常见问题

| 问题 | 解决方法 |
|------|---------|
| 双击没反应 / 闪退 | 确认解压完整，不要直接在压缩包里打开 |
| 提示"缺少 dll" | 安装 [VC++ 运行库](https://aka.ms/vs/17/release/vc_redist.x64.exe) |
| 杀毒软件报毒 | 本游戏不含病毒，选择「允许执行」或添加白名单 |
| 画面很卡 | 在游戏设置里把画质调低，关闭音乐试试看 |

### 📱 Android 手机安装教程

#### 系统要求
- **系统**：Android 8.0 及以上（大部分手机都满足）
- **磁盘空间**：约 500MB
- **处理器**：ARM64 架构（主流手机）

#### 安装步骤（3 步搞定）

```
第1步：把 PVZ-Card-Game_v1.3.0_Android.apk 传到手机
       （微信/QQ/数据线/网盘都可以）
         ↓
第2步：在手机文件管理器里找到 APK，点击安装
       ⚠️ 如果提示"未知来源应用"，选择「允许本次安装」
         ↓
第3步：安装完成！点击桌面上的图标开始游戏
```

#### ❓ 常见问题

| 问题 | 解决方法 |
|------|---------|
| "安装包解析失败" | 重新下载一次，可能下载不完整 |
| "禁止安装未知应用" | 设置 → 安全 → 开启「允许安装未知来源应用」 |
| 安装后打不开 | 检查手机系统是否 ≥ Android 8.0 |
| 画面卡顿 | 游戏内关闭音乐特效，或清理后台应用 |

> ❌ **注意**：iOS 手机暂不支持（Apple 限制了非 App Store 应用安装）

### 🔄 如何更新到新版本？

游戏**没有内置自动更新**，请手动更新：


## 🚀 开发者快速开始（想修改源码看这里）

### 环境准备
1. 安装 [Godot 4.6.x](https://godotengine.org/) 编辑器（标准版，.NET 版不需要）
2. 下载本仓库源码（Code → Download ZIP，或者 git clone）

### 运行游戏
1. 打开 Godot 编辑器 → Import → 选择本目录下的 `project.godot`
2. 导入完成后，点击右上角 ▶ 运行按钮（或按 F5）

### 自行打包发布
```bash
# Windows 桌面版
godot --headless --export-release "Windows Desktop"

# Android APK（需要先在 Godot 编辑器里配置 Android SDK）
godot --headless --export-release "Android"
```

> 也可以直接运行项目根目录的 `release.bat` 一键发布

## 👨‍💻 开发者：发布新版本标准流程

每次更新游戏时，严格按照以下 5 步操作，避免遗漏：

```
┌──────────────────────────────────────────────────────┐
│ Step 1：修改版本号                                    │
│   文件：scripts/version_manager.gd                    │
│   修改 VERSION_MAJOR / VERSION_MINOR / VERSION_PATCH  │
│   例：1.3.0 → 1.3.1（小更新）或 1.4.0（大版本）       │
├──────────────────────────────────────────────────────┤
│ Step 2：写本次更新内容                                │
│   文件：CHANGELOG.md（或 README 的更新日志部分）       │
│   写清楚：新增了什么？修复了什么？有哪些优化？         │
│   参考格式：                                          │
│   ### vX.X.X (YYYY-MM-DD)                             │
│   - ✨ 新增：xxx                                      │
│   - 🔧 修复：xxx                                      │
│   - ⚡ 优化：xxx                                      │
├──────────────────────────────────────────────────────┤
│ Step 3：代码提交到 Git                                │
│   git add -A                                          │
│   git commit -m "release: vX.X.X"                     │
│   git push origin main                                │
├──────────────────────────────────────────────────────┤
│ Step 4：运行打包脚本                                  │
│   双击根目录下的 make_release.bat                     │
│   自动生成两个文件：                                   │
│   • PVZ卡牌游戏_vX.X.X_Windows.zip                    │
│   • PVZ卡牌游戏_vX.X.X_Android.apk                    │
├──────────────────────────────────────────────────────┤
│ Step 5：在 GitHub 创建 Release                        │
│   ① 打开：https://github.com/zanyi123/godot-pvz-.../releases/new
│   ② Choose a tag：填写 vX.X.X 然后点 Create new tag   │
│   ③ Release title：填 vX.X.X                          │
│   ④ Describe：粘贴 Step 2 写的更新内容                 │
│   ⑤ Attach binaries：把 Step 4 生成的两个文件拖进去    │
│   ⑥ 点 Publish release 发布！                         │
└──────────────────────────────────────────────────────┘
```
