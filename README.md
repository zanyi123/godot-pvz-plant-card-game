# 🌱 PVZ 植物卡牌对战游戏

一款基于 **Godot 4.6** 引擎开发的《植物大战僵尸》同人回合制策略卡牌游戏。

---

## 🎮 游戏特色

### 核心玩法
- **四大阵营克制**：法 → 射 → 坦 → 法，掌握克制关系事半功倍
- **双卡组合出牌**：主卡 + 辅卡组合，每回合最多出 2 张牌
- **六阶段结算引擎**：即时效果 → 预处理 → 技能触发 → 阵营克制 → 伤害计算 → 回合结束
- **濒死补救机制**：HP 归零时可出牌自救，增加策略深度

### 双难度人机 AI
| 难度 | 策略特点 |
|------|---------|
| **普通** | 简单攻击贪心算法，适合新手熟悉游戏 |
| **大师** | 多维策略决策：阵营克制 / 双卡组合 / 三回合预测 / 留牌防守 / 组合记忆库 |

### 其他功能
- ✅ 50+ 植物卡牌，覆盖法/射/坦/辅四大阵营
- ✅ 局域网联机对战（Host / Client 模式）
- ✅ 成就系统与存档管理
- ✅ 背景音乐与音效
- ✅ PC 与 Android 移动端双端适配

## 🚀 快速开始

### 方式一：直接运行（推荐）
1. 下载本仓库源码
2. 安装 [Godot 4.6.x](https://godotengine.org/) 编辑器
3. 用 Godot 打开本目录，点击 ▶ 运行按钮

### 方式二：自行打包
```bash
# Android APK 打包
godot --export "Android" ./PVZ_Plant_Card_Game.apk

# Windows 打包
godot --export "Windows Desktop" ./PVZ_Plant_Card_Game.exe
```
