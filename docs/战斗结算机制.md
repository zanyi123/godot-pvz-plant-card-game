# 战斗结算机制说明

> 版本：v1.0
> 更新日期：2026-08-15
> 对应代码：[effect_system.gd](scripts/effect_system.gd), [game_board.gd](scripts/game_board.gd)

---

## 一、整体流程

```
玩家出牌确认 → commit_effects() 即时触发
                ↓
对手出牌 → commit_effects() 即时触发
                ↓
双方出牌完成 → _resolve() 调用 resolve_clash() 六阶段引擎
                ↓
          P1/P2 依次执行阶段1~6效果
                ↓
          最终伤害计算（克制+防御+反弹）
                ↓
          扣血 → buff递减 → 回合结束
```

辅 无克制关系

| 攻击方 | 防守方 | 结果 |
|--------|--------|------|

### 伤害计算规则

**代码位置**：[effect_system.gd#L735-L773](file:///e:/项目储存/pvz-project/pvz-godot/pvz-plant-card-game/scripts/effect_system.gd#L735-L773)

| 场景 | 公式 |
|------|------|
| A克制B，A攻击 > B攻击 | **溢出伤害** = A攻击力 - B攻击力 |
| A克制B，A攻击 ≤ B攻击 | **双方0伤害**（被克制方无法造成伤害） |
| 无克制关系 | **全额互伤** |

| 阶段 | 优先级 | 内容 | 效果ID示例 |
|------|--------|------|-----------|
| **阶段1** | 最低 | 护盾 & 生命恢复 | SHIELD_1/2/4/6, HEAL_1/2/3/4/8 |
| **阶段2** | ↓ | 精力增益 & 减伤 & 破甲 & 连携 | MANA_1-4, REDUCE_DMG_2, ARMOR_PIERCE |
| **阶段3** | ↓ | 阵营克制 | COUNTER_ATK_ZERO, COUNTER_DMG_X3 |

### 各阶段详细效果

#### 阶段1：护盾 & 恢复
- `SHIELD_1/2/4/6` — 增加护盾值
- `HEAL_1/2/3/4` — 固定值回血
- `HEAL_8` — 血量恢复至指定值

#### 阶段2：精力 & 减伤 & 破甲
- `MANA_1-4` — 精力上限增加
- `REDUCE_DMG_2` / `DMG_REDUCE_2` — 减伤
- `ARMOR_PIERCE` / `ARMOR_PEN` — 破甲（无视护盾）
- `BOOST_ATK_HEAL` — 增伤+回血
- `DMG_BUFF_ADD_3` — 固定增伤
- `WEAKEN_ALL` — 弱化对手攻击至1

#### 阶段3：阵营克制
- `COUNTER_ATK_ZERO` — 克制阵营攻击清0（如射手被法师攻击时）
- `COUNTER_DMG_X3` — 对克制阵营伤害×3
- `DMG_BUFF_2X` — 无法被克制时伤害×2
- `NO_COUNTER_DMG_X2` — 无法被克制时伤害×2
- `DMG_BUFF_2X_COUNTER` — 对克制阵营伤害×2

#### 阶段4：增伤
- `SUPPORT_DMG_MULTIPLIER` — 有辅助卡时伤害×3

#### 阶段5：卡牌交互
- `DISCARD_FA` — 弃对手法师阵营牌
- `STEAL_CARD` — 偷对手一张牌
- `STEAL_SH` — 偷对手射手阵营牌
- `COST_TO_HEAL` — 同出牌费用转回血
- `COST_TO_HEAL_SELF` — 自身费用转回血
- `ATK_TO_HEAL` — 对方攻击转回血
- `ABSORB_SHIELD` — 吸收对手护盾
- `BLOCK_NEXT_DRAW` — 对手下回合无法补牌
- `MULTIPLY_DMG_BY_OPPONENT_COUNT` — 伤害×对手出牌数

#### 阶段6：控制 & 防御
- `SHIELD_TURN` — 抵挡一回合攻击
- `ATK_DISABLE` / `SILENCE_ATTACK` — 使对方攻击失效
- `SILENCE` — 沉默对手
- `REFLECT_ATK` — 反弹对方攻击

## 五、伤害计算完整流程

**代码位置**：[effect_system.gd#L743-L800](file:///e:/项目储存/pvz-project/pvz-godot/pvz-plant-card-game/scripts/effect_system.gd#L743-L800)

```
1. 计算原始伤害 _calc_raw_damage()
   ├── 检查攻击禁用（atk_disabled / main_atk_zero）
   ├── 第一步：主卡对主卡的克制判定
   │   ├── 弱化处理（影响主卡攻击力）
   │   ├── 阵营克制判定 → 溢出/清零/全额
   │   └── 计算主卡伤害
   ├── 第二步：计算辅助卡攻击力（独立计算，不受克制影响）
   ├── 第三步：总伤害 = 主卡伤害 + 辅助卡攻击力
   ├── 应用 atk_boost（加算到总伤害）
   ├── 应用弱化（影响总伤害）
   └── 乘算（dmg_multiplier）

2. 防御处理 _apply_defense()
   ├── 减伤（dmg_reduce buff）
   ├── 护盾吸收（破甲时跳过）
   └── block_turn 完全免疫

3. 反弹处理
   ├── 若有反弹标记 → 伤害反弹给对方

4. 扣血 _do_damage()
```

### 伤害计算详细步骤

#### 步骤1：主卡克制判定
```gdscript
# 主卡攻击力
my_main_atk = my_main.atk
opp_main_atk = opp_main.atk

# 弱化处理
if weakened:
    my_main_atk = min(my_main_atk, 1)

# 阵营判定（基于主卡阵营）
if i_counter_opp:
    # 我克制对手：主卡伤害 = max(0, my_main_atk - opp_main_atk)
    main_damage = max(0, my_main_atk - opp_main_atk)
elif opp_counters_me:
    # 对手克制我：主卡伤害为0
    main_damage = 0
else:
    # 无克制：主卡全额伤害
    main_damage = my_main_atk
```

#### 步骤2：辅助卡独立计算
```gdscript
# 辅助卡攻击力（不受克制影响）
support_atk = sum(card.atk for card in my_cards if card != my_main)
```

#### 步骤3：总伤害计算
```gdscript
# 总伤害 = 主卡伤害 + 辅助卡攻击力
total_damage = main_damage + support_atk

# 应用 atk_boost
total_damage += atk_boost

# 应用弱化
if weakened:
    total_damage = min(total_damage, 1)

# 应用乘算
total_damage = total_damage * dmg_multiplier
```

### 伤害计算示例

**场景**：玩家A出法主卡(atk=3) + 辅卡(atk=2)，玩家B出射主卡(atk=4)

| 步骤 | 计算 | 结果 |
|------|------|------|
| 主卡克制判定 | 法→射，3 < 4 | main_damage = 0 |
| 辅助卡计算 | 辅卡atk=2 | support_atk = 2 |
| 总伤害 | 0 + 2 | **2点伤害** |

**场景**：玩家A出法主卡(atk=5) + 辅卡(atk=2)，玩家B出射主卡(atk=4)

| 步骤 | 计算 | 结果 |
|------|------|------|
| 主卡克制判定 | 法→射，5 > 4 | main_damage = 5-4 = 1 |
| 辅助卡计算 | 辅卡atk=2 | support_atk = 2 |
| 总伤害 | 1 + 2 | **3点伤害** |

#### 步骤4：防御处理
```gdscript
func _apply_defense(defender, damage, has_armor_pierce):
    # ① 减伤（百分比）
    damage = damage * (1 - dmg_reduce / 100)
    
    # ② 护盾吸收（破甲跳过）
    if not has_armor_pierce:
        absorbed, damage = consume_shield(ps, damage)
    
    # ③ block_turn 完全免疫
    if has_block_turn:
        return 0
    
    return damage
```

#### 步骤5：反弹处理
```gdscript
# 反弹在防御处理之后
if P1_reflect_atk and p1_damage > 0:
    p2_damage += p1_damage  # 伤害反弹给对方
    p1_damage = 0
```

## 六、关键效果机制详解

### 1. 护盾吸收
**代码位置**：[effect_system.gd#L179-L196](file:///e:/项目储存/pvz-project/pvz-godot/pvz-plant-card-game/scripts/effect_system.gd#L179-L196)

- 按护盾值依次吸收伤害
- 破甲效果可绕过护盾
- 返回 `[已吸收, 剩余伤害]`

### 2. 弱化机制
**代码位置**：[effect_system.gd#L748-L749](file:///e:/项目储存/pvz-project/pvz-godot/pvz-plant-card-game/scripts/effect_system.gd#L748-L749)

- 被弱化后攻击力 ≤ 1
- 同时影响原始atk和克制溢出计算
- 由 `WEAKEN_ALL` 效果或 `weaken_all_opponent` handler 触发

### 3. 反弹机制
**代码位置**：[effect_system.gd#L705-L712](file:///e:/项目储存/pvz-project/pvz-godot/pvz-plant-card-game/scripts/effect_system.gd#L705-L712)

- 反弹在防御处理之后
- 反弹后原伤害归0
- 由 `REFLECT_ATK` 效果触发

### 4. Buff衰减
**代码位置**：[effect_system.gd#L198-L211](file:///e:/项目储存/pvz-project/pvz-godot/pvz-plant-card-game/scripts/effect_system.gd#L198-L211)

- `duration > 0`：每回合 -1
- `duration = -1`：永久buff
- 回合结束时调用 `tick_buffs()`

### 5. 破甲机制
**代码位置**：[effect_system.gd#L405-L409](file:///e:/项目储存/pvz-project/pvz-godot/pvz-plant-card-game/scripts/effect_system.gd#L405-L409)

- 设置 `armor_pierce` 标记
- 在防御处理时跳过护盾吸收
- 由 `ARMOR_PIERCE` 或 `ARMOR_PEN` 效果触发

## 七、补救回合机制

**代码位置**：[game_board.gd#L1981-L2017](file:///e:/项目储存/pvz-project/pvz-godot/pvz-plant-card-game/scripts/game_board.gd#L1981-L2017)

```
结算后检测濒死：
├── 仅P1濒死 → 进入REMEDY阶段（P1打治疗卡自救）
├── 仅P2濒死 → 进入REMEDY_AI阶段（P2自动补救）
└── 双方濒死 → P2先补救 → P1再补救（保证双方都有机会）
```

### 补救阶段说明

| 阶段名 | 触发条件 | 行为 |
|--------|----------|------|
| REMEDY | 仅P1濒死 | 玩家打治疗卡自救 |
| REMEDY_AI | 仅P2濒死 | AI自动打治疗卡补救 |
| REMEDY_AI (双方) | 双方濒死 | P2先补救，再P1补救 |
